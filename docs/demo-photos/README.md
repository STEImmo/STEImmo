# Demo-Fotos für die Wohnungsansicht

Diese vier Bilder wurden mit Imagegen erzeugt. Sie zeigen fiktive Räume und sind keine Fotos der tatsächlichen Immobilie. Sie sind auf ausdrücklichen Nutzerwunsch als Beispieldateien für Tests und Vorführungen im Repository enthalten. Die JPEG-Dateien wurden durch die normale Wohnungsfoto-Validierung verarbeitet; ursprüngliche Metadaten wurden entfernt.

## Einbinden

Mit einem Mitarbeiterkonto in der Verwaltung Wohnung 001 bearbeiten und „Wohnungsfotos verwalten“ öffnen. Die Dateien einzeln in folgender Reihenfolge hochladen:

| Datei | Bildbeschreibung |
|---|---|
| 01-wohnbereich.jpg | Demo – KI-Beispiel: Wohnbereich |
| 02-kueche.jpg | Demo – KI-Beispiel: Küche |
| 03-schlafzimmer.jpg | Demo – KI-Beispiel: Schlafzimmer |
| 04-bad.jpg | Demo – KI-Beispiel: Bad |

Das erste Bild wird zum Titelbild. Mit vier Bildern lässt sich der Stapelhinweis „+1 Foto“ auf dem dritten Vorschaubild und das Durchblättern der gesamten Galerie testen. In der aktuellen lokalen Umgebung sind diese vier Bilder bereits bei Wohnung 001 hochgeladen; dort ist kein erneuter Upload nötig.

Die Dateien werden beim Start nicht automatisch in die Datenbank importiert. Der Upload über die Verwaltung ordnet sie einer Wohnung zu und speichert Arbeitskopien im Medienbereich. Reguläre Uploads und echte Nutzerdaten bleiben außerhalb von Git. Vor einer echten Veröffentlichung die Demo-Bilder über die Fotopflege entfernen und durch passende Originalfotos ersetzen.
